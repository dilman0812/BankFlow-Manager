\# Bank Management System



A desktop-based Java application that simulates core banking operations.



\## Prerequisites

\*   Java JDK 8 or higher

\*   MySQL Server

\*   MySQL Connector/J (JDBC Driver)

## Current Features

*   **Login Interface:** A  banking authentication window with card number and PIN input fields
*   **Account Registration Form (SignupOne):** Comprehensive user details collection including:
    *   Personal information (full name, date of birth, gender)
    *   Contact details (email address)
    *   Address details (city, state, PIN code)
    *   Form validation and error handling
